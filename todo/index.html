개발키트 정해야 할 부분

작성일: 2026-10-02 관련 문서: 사업모델.md, 개발키트 가이드북.md, 자동개발 플랫폼 가이드북.md

1. 상품 명칭

  • 개발키트, 자동개발 플랫폼 네이밍
  • 상표, 디자인 출원, 프로그램 저작권 등 관련 있음

2. 가격표

  • 개발키트 가격 정의
  • 구매 옵션, 유지보수, AI API 등 고려
구분 [입문/소규모] 개발 키트 [고성능/실무] 하이브리드 키트 [24시간] AI 비서 서비스
추천 대상 초보 개발자, 초기 테스트 및 소규모 사이트 실무 가부하 제어 및 로컬 백업망 필수 기업 개인 PC 가동 없이 24시간 무인 가동 기업
초기 구축비 (1회) 150만 ~ 250만 원 350만 ~ 500만 원 이상 별도 구축비 협의 (기존 키트 연동)
월 유지보수비 월 10만 ~ 15만 원 월 20만 ~ 30만 원 월 15만 ~ 25만 원
인프라/스토리지 보유 PC 또는 기본 로컬 서버 가상화 OS(Hypervisor) + HDD/SSD 선택 서버 / VPS 상시 가동 스토리지
소프트웨어 스택 XAMPP 기반 통합 스택 Apache + InnoDB DB + PHP-FPM / FastCGI 24시간 AI 자동화 비서 기본 탑재
주요 제공 기능 원클릭 백업/대시보드, 템플릿A 자원 독립, 하이브리드 백업망, 원격 개발 계정 연동 후 24시간 무인 자동 실행

3. 컨설팅 기준

  • 3개월 이내 10회 100분 무상 컨설팅 정의
  • 무상/유상 서비스 구분

4. 라이선스 약관

  • 양도양수 기준
  • 재판매 별도 라이선스 청구 또는 금지 조항
  • 하드웨어 A/S 보증 기간
  • 소프트웨어 유지보수 기간
  • 반품·환불 정책 확정
  • 보안 및 책임 범위 정의

5. 교육

  • 사용법 동영상 제작 (개발키트, 자동개발 플랫폼)
  • 교재 제작

6. 솔루션몰

  • 솔루션몰 상품(재고관리, 반출입관리, 장비관리 등) 템플릿A 소스 적용 → 개발팀 지원
  • 데모 체험 환경 구현 → 개발팀 지원
  • 템플릿A 적용된 상세페이지 작업
